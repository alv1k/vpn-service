# Исследование и архитектурный план: OpenFlux как аварийный стелс-шлюз для VPN-сервиса

> **Дата составления:** Октябрь 2026 г.  
> **Статус:** Концептуальный и архитектурный дизайн резервного шлюза  
> **Контекст:** Инфраструктура сервиса `tiin` (Hetzner DE ⇄ Selectel SPB RU)

---

## 1. Суть и концепция OpenFlux

**OpenFlux** — это открытый инструмент сетевого туннелирования (IPv4 TCP/UDP) на языке Go (лицензия GPLv3), использующий подход **Pluggable Transports** (подключаемых транспортов).

### Принцип работы
Вместо прямого соединения клиента с сервером по VPN-протоколам (WireGuard, OpenVPN, VLESS, Hysteria), трафик инкапсулируется в легитимные сессии доверенных платформ:
```
[Клиент (любая ОС)] 
        │ (TUN / SOCKS5 / VPN)
        ▼
   [Транспорт]  ───►  [Облачный сервис: Yandex / Mail.ru / Centrifugo / WebRTC]
        │
        ▼
   [Exit Node]  ───►  [Интернет / Внутренний шлюз]
     ├── L3: raw SNAT/DNAT (Linux, root, максимальная скорость)
     └── L4: gVisor netstack (любая ОС, без root, в контейнере)
```

### Доступные транспорты
1. `yandex` — WebSocket Яндекс Документов (встроенный автосолвер Proof-of-Work капчи).
2. `vyandex` — Yandex Volga (HTTP-relay + WS, авторизация через `cookies.txt`).
3. `boards` — Яндекс Доски (WebSocket).
4. `mailru` — Облако Mail.ru Docs (WebSocket через публичные ссылки).
5. `oneme` — MAX / OneMe (WebRTC DataChannel).
6. `cupsonline` — Cups.online (Centrifugo WebSocket-комнаты).
7. `script` — скриптовый JS-движок (Goja) для написания новых транспортов без перекомпиляции ядра.

## 2. Сравнение с текущим Smart Split Tunneling (Selectel SPB ⇄ Hetzner DE)

В текущей архитектуре сервиса трафик разделяется на RU-ноде (Selectel):
* `.ru`, банки, Госуслуги ➔ локальный выход в РФ (Selectel SPB).
* Зарубежный/заблокированный ➔ внутренний L3-мост AmneziaWG / olcRTC ➔ Hetzner DE.

### Что улучшает OpenFlux:

| Угроза со стороны ТСПУ / РКН | Текущий стек (Hysteria2 / VLESS) | Связка со стелс-транспортом OpenFlux |
|---|---|---|
| **Блокировка IP-адреса хостинга** | Клиент подключается к `139.100.207.18`. При бане пула Selectel связь падает. | Клиент подключается к IP-адресам **Яндекса/Mail.ru**. Серверного IP в логах ТСПУ нет. |
| **Режим «Белых списков Рунета»** | Хостинги не входят в соц. значимый белый список — соединение блокируется. | Яндекс и Mail.ru находятся в вершине белых списков — канал продолжает жить. |
| **Активное зондирование (Active Probing)** | На сервере открыты порты (`8443`, `35443`), сканеры могут их тестировать. | В режиме L4 сервер **не открывает публичных портов** — он сам опрашивает Яндекс исходящим соединением. |
| **Несоответствие IP и SNI (Reality)** | Запрос к `yahoo.com` летит на IP в РФ — ТСПУ может фиксировать аномалию. | Запрос к `docs.yandex.ru` летит на реальный CDN Яндекса — 100% легитимный профиль. |

## 3. Доступ к Госуслугам и банкам (Белосписочные ресурсы)

Госуслуги, Сбер, Т-Банк и ФНС блокируют зарубежные IP-адреса по GeoIP (ошибка 403 / сброс соединения).

### Как обеспечивается доступ:
1. **Основной сценарий (Split-Tunneling на клиенте)**:
   * На Android: через **Per-App Routing** (банки и Госуслуги исключаются из туннеля и идут напрямую).
   * На ПК: OpenFlux в режиме SOCKS5 (`127.0.0.1:1080`) + расширение браузера (ZeroOmega) с правилом *«gosuslugi.ru и *.ru — напрямую, заблокированное — через SOCKS5»*.
2. **Серверный сценарий (Exit Node на Selectel SPB)**:
   * Exit Node ставится на российском сервере в Selectel.
   * Трафик после выхода из Яндекса попадает в локальный Xray-маршрутизатор:
     * РФ-трафик и Госуслуги выходят локально в СПб с белым российским IP.
     * Зарубежный трафик пересылается по L3-мосту в Германию.

## 4. Архитектура интеграции в Telegram-бот и User Flow

### Почему нельзя добавить в общую ссылку подписки
Стандартные клиенты (v2rayNG, Streisand, Happ, V2Box) базируются на ядрах Xray/sing-box и не поддерживают wire-протокол OpenFlux (`openflux://`).

### Оптимальная бизнес-модель: «Два ключа в одной подписке»

Не нужно усложнять онбординг для 95% пользователей. OpenFlux позиционируется как **эксклюзивная страховка («Аварийный шлюз»)**.

#### 1. Онбординг (Триал или Покупка):
* Пользователь берет тест (3 дня) или оплачивает подписку.
* Ему выдается стандартная скоростная подписка под Happ / v2rayNG (Hysteria2, Reality Vision).
* Это дает максимальную скорость (до 1 Гбит/с) и поддержку 4K YouTube.

#### 2. Главное меню кабинета:
```text
┌──────────────────────────────────────────────┐
│  👤 Личный кабинет: Подписка активна (до...)  │
│  Статус: 🟢 Активна                           │
└──────────────────────────────────────────────┘
  🚀 Подключить основной VPN (Быстрый)
  🛡️ Резервный шлюз «Стелс» (Яндекс)
  💳 Продлить подписку
```

#### 3. Флоу при нажатии «🛡️ Резервный шлюз»:
Если подписка/триал активны, бот отправляет сообщение:
> 🛡️ **Резервный шлюз «TIIN Стелс»**  
> *Используйте, если ваш оператор глушит обычный VPN или включил белые списки. Трафик маскируется под документы Яндекса.*  
> 
> 1. Установите приложение (файл прикреплен ниже)  
> 2. Нажмите кнопку подключения:  
> 🔗 **[ Подключить профиль в 1 клик (`openflux://...`) ]**

#### 4. Технический контроль доступа (Биллинг):
* **Вариант 1 (Криптографический)**: OpenFlux Exit Node использует `--encryption-key-file`. Бот выдает ссылку с актуальным ключом только активным пользователям. Плановая ротация ключа/документа раз в 1-2 недели.
* **Вариант 2 (Аутентификация через Xray)**: Exit Node в режиме L4 направляет трафик на локальный SOCKS5 Xray с проверкой UUID пользователя по базе MySQL.

## 5. Преодоление барьера дистрибуции (Отсутствие в Google Play / App Store)

OpenFlux отсутствует в официальных магазинах приложений из-за политики платформ к инструментам обхода блокировок.

### Практические решения:
1. **Прямая отправка APK в Telegram-боте (Основной способ)**:
   * Бот прикрепляет файл `OpenFlux.apk` (~20 МБ) прямо в диалог Telegram с короткой видео-инструкцией по установке.
   * Для пользователей из РФ это привычный паттерн (аналогично приложениям Сбера, Т-Банка, Альфы).
   * Подается как преимущество: *«Специальная бронебойная сборка, защищенная от удаления из Google Play»*.
2. **RuStore (Опционально)**:
   * Сборка брендированного форка под RuStore (где российская модерация пропускает утилиты).
3. **iOS ограничения**:
   * Для iOS доступен TestFlight (бета-канал), поэтому на iOS упор делается на скоростные VLESS-xHTTP / Reality в приложении Happ / Streisand, а OpenFlux предлагается для Android и Windows/macOS.

---

## 6. Резюме для сервиса

* **Не заменять текущий стек**: Hysteria2 и VLESS-Reality остаются основными драйверами скорости и удобства.
* **Использовать OpenFlux как аварийную подушку безопасности**: уникальное торговое предложение (УТП), гарантирующее доступ при тотальных отключениях внешнего интернета и жестких фильтрах ТСПУ.
